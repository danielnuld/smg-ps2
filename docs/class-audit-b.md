# Class audit B (2026-11-18)

The placed classes whose Petari source is `src/Game/MapObj/` N to Z, `src/Game/Map/`, `src/Game/Ride/` and
`src/Game/Gravity/`, most placed first (out/census.json), against what the port does. Agent audit-b.

How to read the verdicts:

- **fixed**: read against the Petari file line by line, the gaps ported in the PR named.
- **issue n**: read, a port of its own; written up.
- **ok**: read against the Petari file, nothing found.
- **ported, gaps marked**: the port has the class's nerves (its comment block names the .cpp; every Petari
  `startSound` name and nearly every action name of the file is spelled in the engine: scratch check) and its own
  `ponytail:` marks say what is left; the marks are quoted. NOT re-read line by line in this pass: the next pass
  should take these in order.
- **skipped**: another agent's class today.

Found on the way, engine-wide: MapPartsRailMover (every rail-moving map part; #654, fixed). 
SimpleMapObj rows are static in Petari but for MapObjActor::initialize's services by name and argument (the
ColorChange BRK frame of arg0, TexChange of arg1, the shadow length of arg2, the appear riddle SE, the
object's own effect): those are engine-wide tables, not audited class by class here.

Where the gaps were: in the earliest ports (their comment block says `X.cpp:` and not `X.cpp after Petari`).
Every class read in this pass whose block is of the later kind matched (SubmarineSteam, PalmIsland,
TimerMoveWall, LavaShellTower, QuestionCoin's throw); the earlier kind gave SpaceMine, NeedlePlant, SnowMan,
StarPieceGroup, CoinGroup, PunchBox, SimpleBreakableObj. A later block's own `ponytail:` can still hide a whole
nerve (WaterLeakPipe's Freeze behind "no Ice Mario", written before Ice Mario was ported; the treasure boxes'
chips), and a mark can be stale the other way (CoinGroup's "no appear switch": pick_shown reads it).
Next pass, in this order (not re-read yet, early ports): PlantMember (PlantGroup's second half), WoodBox's
checks, WaterPlant, PowerStar, SmallStone, SpaceCocoon, PunchingKinoko, NoteFairy, Fluff, JumpBranch,
Plant, then the rest of the table's `ported, gaps marked` rows.
